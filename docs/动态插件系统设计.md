# MathStudio 动态插件系统设计

本文档说明 MathStudio 的动态插件架构、C ABI、生命周期、工程序列化、构建方式和使用限制。

---

## 1. 目标

把原本“插件源码必须编译进主程序”的静态模式改成：

```text
MathStudio.exe
    ↓ 启动时扫描
plugins/*.dll
    ↓ LoadLibrary
动态注册插件类型
    ↓
工程加载 / 菜单创建时实例化
```

实现目标：

- 插件可以单独编译成 DLL；
- 主程序不需要重新链接插件；
- 工程文件可以保存动态插件类型；
- 动态插件可以保存/恢复自己的状态；
- 插件崩溃或 DLL 不兼容时不影响内置插件；
- 插件只用 C ABI，避免跨 DLL 的 C++ STL 风险。

---

## 2. 为什么不用 C++ Plugin 跨 DLL

主程序内部的 `Plugin` 是 C++ 虚基类：

```cpp
class Plugin {
public:
    virtual ~Plugin() = default;
    virtual std::string name() const = 0;
    virtual void update(Object&, float) = 0;
};
```

如果 DLL 直接返回 `Plugin*`，会依赖：

- 相同编译器版本；
- 相同 C++ 标准库版本；
- 相同 `/MD` 或 `/MT` 运行时；
- 相同 `std::string`、`std::vector`、`unique_ptr` 布局；
- 相同异常处理设置；
- 相同 RTTI 设置。

任何一项不同都可能在 DLL 边界崩溃。

因此动态插件边界只允许：

```c
纯 C 结构体
C 函数指针
void*
float/int
```

插件内部仍然可以用 C++、`std::sin`、类、RAII，但这些都封装在 DLL 内部。


## 4. C ABI 定义

头文件：

```text
src/plugins/plugin_api.h
```

### 4.1 Object API

插件不能直接持有 `Object*`，只能拿到函数表：

```c
typedef struct MsObjectApi {
    void* object;

    MsVec3 (*get_position)(void* object);
    void (*set_position)(void* object, MsVec3 position);

    MsVec3 (*get_color)(void* object);
    void (*set_color)(void* object, MsVec3 color);
} MsObjectApi;
```

调用示例：

```cpp
MsVec3 position = api->get_position(api->object);
position.z += 0.1f;
api->set_position(api->object, position);
```

`object` 是不透明句柄，插件不能解引用。

### 4.2 插件实例

```c
typedef struct MsPlugin {
    void* instance;

    const char* (*type_name)(void* instance);

    void (*destroy)(void* instance);
    void (*destroy_plugin)(MsPlugin* plugin);

    void (*on_attach)(void* instance, const MsObjectApi* api);
    void (*update)(void* instance, const MsObjectApi* api,
                   float delta_seconds);
    void (*set_time)(void* instance, const MsObjectApi* api,
                     float absolute_time);

    size_t (*save)(void* instance, void* buffer, size_t capacity);
    int (*load)(void* instance, const void* data, size_t size);
} MsPlugin;
```

### 4.3 DLL 导出

每个插件 DLL 必须导出两个函数：

```c
const char* mathstudio_plugin_type(void);
MsPlugin* mathstudio_create_plugin(void);
```

## 5. 生命周期

```text
程序启动
  ↓
DynamicPluginManager::discoverDefault()
  ↓ 扫描 plugins/
注册 type -> create 函数
  ↓
加载 .math / Object 菜单创建
  ↓
DynamicPluginManager::create(type)
  ↓
DLL create_plugin()
  ↓
DynamicPlugin 包装 MsPlugin
  ↓
Object::addPlugin()
  ↓
on_attach
  ↓
每帧 update
  ↓
时间轴 set_time
  ↓
保存 save
  ↓
析构 destroy_plugin
```

### on_attach

适合记录初始位置：

```cpp
state->origin = api->get_position(api->object);
```

### update

每帧调用，接收 delta 秒：

```cpp
state->time += deltaSeconds;
api->set_position(api->object, positionAt(state, state->time));
```

### set_time

时间轴拖动时使用绝对时间：

```cpp
state->time = absoluteTime;
api->set_position(api->object, positionAt(state, absoluteTime));
```

### destroy_plugin

必须由 DLL 自己释放 `MsPlugin` 和 `instance`，这样 `delete` 与 `new` 在同一个 DLL/CRT 中完成。

## 6. 工程序列化

`.math` 中插件仍按现有格式保存：

```text
typeId 字符串
插件状态
```

对于动态插件：

```text
typeId = "WaveMotionPlugin"

U32 状态字节数
状态字节 blob
```

宿主 `DynamicPlugin::save()`：

1. 先调用 `save(instance, nullptr, 0)` 查询需要多少字节；
2. 分配临时 buffer；
3. 再调用 `save(instance, buffer, size)`；
4. 把 U32 长度和原始字节写入工程。

加载时：

```text
读取 U32 长度
读取原始字节
调用 DLL 的 load()
```

如果 DLL 不存在：

```text
createPluginByType("WaveMotionPlugin") -> nullptr
工程加载失败
```

不会崩溃，也不会误加载其他插件。

## 7. 构建与部署

### 7.1 CMake 示例目标

```cmake
add_library(WaveMotionPlugin SHARED
    src/dynamic_plugins/wave_motion_plugin.cpp
    src/plugins/plugin_api.h
)

target_include_directories(WaveMotionPlugin PRIVATE
    src/plugins
)

add_custom_command(TARGET WaveMotionPlugin POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E make_directory
        "$<TARGET_FILE_DIR:VulkanTutorial>/plugins"
    COMMAND ${CMAKE_COMMAND} -E copy_if_different
        "$<TARGET_FILE:WaveMotionPlugin>"
        "$<TARGET_FILE_DIR:VulkanTutorial>/plugins/WaveMotionPlugin.dll"
)
```

构建后目录：

```text
build/Release/
├── VulkanTutorial.exe
└── plugins/
    └── WaveMotionPlugin.dll
```

发布包同样：

```text
MathStudio.exe
plugins/
  WaveMotionPlugin.dll
```

### 7.2 手工编译插件

只要满足：

- 导出两个 C 函数；
- 使用相同的 MSVC 工具集；
- 64 位；
- 不依赖主程序内部 C++ 符号；

就可以单独编译成 DLL。

## 8. 扫描顺序

`DynamicPluginManager::discoverDefault()` 会尝试：

```text
<exe目录>/plugins
<当前工作目录>/plugins
<当前工作目录>/../plugins
```

同一个类型只注册一次。

## 9. 编辑器集成

插件编辑器新增：

```text
创建动态插件
编译并加载
扫描动态插件
```

### 9.1 创建动态插件

编辑器把动态插件源码写到：

```text
<源码根目录>/src/dynamic_plugins/editor_plugin.cpp
```

生成的是纯 C ABI DLL 源码，不依赖主程序的 C++ 类型。

### 9.2 编译并加载

点击“编译并加载”后，宿主会：

```text
保存编辑器中的源码
  ↓
执行 cmake --build --target MathStudioEditorPlugin
  ↓
读取 build/Release/MathStudioEditorPlugin.dll
  ↓
复制为 plugins/EditorPlugin_<timestamp>.dll
  ↓
重新扫描 plugins/
  ↓
按类名创建动态插件
  ↓
挂载到当前 Object
```

之所以复制成带时间戳的新文件名，是因为 Windows 不能覆盖
已经被 `LoadLibrary` 加载的 DLL。旧 DLL 保持加载，旧插件实例
会继续使用旧代码；新建的实例使用新 DLL。

### 9.3 源码根目录

编辑器需要知道 CMake 工程目录。

优先级：

```text
MATHSTUDIO_SOURCE_DIR 环境变量
  ↓
当前工作目录向上的 CMakeLists.txt
  ↓
D:/Program/VulkanProject/math
```

构建目录默认：

```text
<源码根目录>/build
```

可以用：

```text
MATHSTUDIO_BUILD_DIR
```

覆盖。

CMake 可执行文件默认：

```text
C:/Program Files/CMake/bin/cmake.exe
```

可以用：

```text
MATHSTUDIO_CMAKE
```

覆盖。

### 9.4 扫描动态插件

点击“扫描动态插件”会重新扫描：

```text
<exe>/plugins
<cwd>/plugins
<cwd>/../plugins
```

发现的新类型可以立即用于：

```text
类名 → 应用到当前 Object
```

如果 `class` 名称已经注册为动态插件：

```text
DynamicPluginManager::create(className)
```

成功则挂载动态插件。

否则仍然回退到：

```cpp
CodePlugin
```

作为源码标记。

## 10. 安全与限制

### 安全

`LoadLibrary` 会执行 DLL 的 DllMain 和静态初始化代码。

只应加载可信来源的插件：

```text
不加载网上下载的未知 DLL
不把任意目录加入插件扫描路径
```

### 当前限制

动态插件目前只支持：

- 读写 Object 位置；
- 读写 Object 颜色；
- 每帧更新；
- 时间轴定位；
- 生成多个绘制实体（使用宿主 Object 的 Mesh）；
- 保存/恢复自定义状态。

暂不支持：

- 动态插件上传全新的 Mesh；
- 自定义 ImGui 参数面板；
- 插件间依赖；
- 热卸载已加载 DLL；
- 运行中替换同名 DLL。

### 多实体 API

`MsPlugin` 增加：

```c
size_t (*collect_instances)(
    void* instance,
    const MsObjectApi* api,
    const MsRenderInstance** out);
```

每个 `MsRenderInstance` 包含：

```c
typedef struct MsRenderInstance {
    float transform[16]; // 列主序
    float color[4];
    int transparent;
} MsRenderInstance;
```

插件返回自己的实例数组，宿主用 Object 的 Mesh 创建多个实体。
示例 `WaveMotionPlugin` 现在会生成一个主立方体和 17 个轨迹立方体。

### 热重载

Windows 不允许覆盖已被 `LoadLibrary` 加载的 DLL。

因此：

```text
修改源码
  ↓
重新编译 DLL
  ↓
关闭 MathStudio
  ↓
替换 plugins/xxx.dll
  ↓
重新启动
```

不要在程序运行时覆盖已加载 DLL。

## 11. 版本兼容建议

当前 ABI 没有显式版本字段，建议后续增加：

```c
#define MATHSTUDIO_PLUGIN_ABI_VERSION 1

uint32_t mathstudio_plugin_abi_version(void);
```

宿主扫描时比较版本，不匹配则跳过。

插件状态 blob 也应增加版本号：

```text
U32 stateVersion
U32 stateSize
bytes
```

当前示例使用固定 `WaveState`，只适合同一版本。
