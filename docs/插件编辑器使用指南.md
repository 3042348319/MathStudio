# MathStudio 插件代码编辑器使用指南

本文以一个实际插件为例：

> 让正方体在前视图中沿正弦曲线来回运动。

同时说明插件代码编辑器能做什么、不能做什么，以及完整的使用流程。

> 动态插件设计、C ABI、DLL 加载和序列化细节见：
>
> [动态插件系统设计.md](<C:\Users\30423\Documents\deepseek-harness\default-workspace\动态插件系统设计.md>)

## 0. 两种插件模式

MathStudio 现在支持两种插件：

### 内置插件

编译进 `MathStudio.exe`，例如：

```text
CoordinateSystemPlugin
SineParticlePlugin
SineMotionPlugin
```

### 动态插件

编译成 DLL，放在：

```text
MathStudio.exe
└── plugins/
    └── WaveMotionPlugin.dll
```

启动时自动扫描，工程可以保存/加载动态插件类型。

编辑器中的按钮：

```text
扫描动态插件
```

会重新扫描 `plugins/`，然后把已编译 DLL 的类型挂到当前 Object。

示例：

```text
Object → 动态波浪立方体
```

它由 `plugins/WaveMotionPlugin.dll` 驱动。

## 1. 先看效果

打开 MathStudio 后：

1. 新建或打开一个工程；
2. 点击工程窗口菜单栏的 `Object`；
3. 选择 `正弦运动立方体`；
4. 按小键盘 `1` 进入前视图；
5. 按 `T` 显示时间轴，点击播放。

立方体会在 **XZ 平面** 内沿正弦曲线运动：

```text
Z
↑
│      ╭──╮
│    ╭╯  ╰╮
│  ╭╯      ╰╮
└──┴────────┴──→ X
```

前视图中：

- 屏幕水平方向是 X；
- 屏幕垂直方向是 Z；
- Y 保持不变；
- 按 `Esc` 退出正交视图，恢复原来的透视视图。

## 2. 插件代码编辑器能做什么

快捷键：

```text
Ctrl+`
```

编辑器可以：

- 查看内置插件源码；
- 为当前 Object 选择插件；
- 新建 `.h/.cpp` 插件源码；
- 修改并保存源码；
- 将源码文件作为 CodePlugin 标记附加到当前 Object。

### 重要限制

#### 重新加载工程会执行源码吗？

**不会。**

重新打开 `.math` 工程时，程序只是恢复了：

```cpp
CodePlugin
```

以及它保存的：

```text
类名
源文件路径
```

`CodePlugin::load()` 只读取这两个字符串，不会：

- 编译 C++；
- 生成 DLL；
- 动态加载源码；
- 实例化源码中的类。

因此单纯“插入源码 → 保存工程 → 重新加载工程”不会执行源码内容。

源码真正运行必须经过：

```text
编辑器新建源码
    ↓
编辑代码并保存
    ↓
重新 CMake 构建
    ↓
插件类进入可执行文件
    ↓
在代码中注册工厂 / 挂载到 Object
    ↓
运行并测试
```

## 3. 示例插件

文件位置：

```text
src/plugins/sine_motion_plugin.h
src/plugins/sine_motion_plugin.cpp
```

### 3.1 头文件

```cpp
#pragma once

#include "plugin.h"

#include <glm/glm.hpp>
#include <string>

class SineMotionPlugin : public Plugin {
public:
    SineMotionPlugin(float horizontalAmplitude = 0.8f,
                     float verticalAmplitude = 0.35f,
                     float frequency = 3.0f,
                     float speed = 1.4f,
                     float phase = 0.0f);

    void onAttach(Object& owner) override;
    void update(Object& owner, float deltaSeconds) override;
    void setTime(Object& owner, float time) override;

    std::string name() const override;
    std::string summary() const override;

    void save(BinaryWriter& out) const override;
    bool load(BinaryReader& in) override;

    float horizontalAmplitude() const;
    void setHorizontalAmplitude(float value);
    float verticalAmplitude() const;
    void setVerticalAmplitude(float value);
    float frequency() const;
    void setFrequency(float value);
    float speed() const;
    void setSpeed(float value);
    float phase() const;
    void setPhase(float value);

private:
    glm::vec3 positionAt(float time) const;

    glm::vec3 origin_{0.0f};
    float horizontalAmplitude_ = 0.8f;
    float verticalAmplitude_ = 0.35f;
    float frequency_ = 3.0f;
    float speed_ = 1.4f;
    float phase_ = 0.0f;
    float time_ = 0.0f;
};
```

### 3.2 运动公式

```cpp
glm::vec3 SineMotionPlugin::positionAt(float time) const {
    const float x = origin_.x +
                    horizontalAmplitude_ *
                        std::sin(speed_ * time + phase_);

    const float z = origin_.z +
                    verticalAmplitude_ *
                        std::sin(frequency_ * (x - origin_.x) + phase_);

    return glm::vec3(x, origin_.y, z);
}
```

其中：

- `x` 是水平方向的往复位移；
- `z` 是 X 的正弦函数；
- `y` 保持初始值；
- 因此从正视图看是一条正弦曲线。

### 3.3 生命周期

```cpp
void SineMotionPlugin::onAttach(Object& owner) {
    origin_ = owner.position();
    time_ = 0.0f;
    owner.setPosition(positionAt(0.0f));
}

void SineMotionPlugin::update(Object& owner, float deltaSeconds) {
    time_ += deltaSeconds;
    owner.setPosition(positionAt(time_));
}

void SineMotionPlugin::setTime(Object& owner, float time) {
    time_ = time;
    owner.setPosition(positionAt(time_));
}
```

`setTime()` 用于时间轴拖动；它按绝对时间定位，而不是累加帧时间。

### 3.4 保存 / 加载

```cpp
void SineMotionPlugin::save(BinaryWriter& out) const {
    out.writeVec3(origin_);
    out.writeFloat(horizontalAmplitude_);
    out.writeFloat(verticalAmplitude_);
    out.writeFloat(frequency_);
    out.writeFloat(speed_);
    out.writeFloat(phase_);
    out.writeFloat(time_);
}

bool SineMotionPlugin::load(BinaryReader& in) {
    origin_ = in.readVec3();
    horizontalAmplitude_ = std::max(0.0f, in.readFloat());
    verticalAmplitude_ = std::max(0.0f, in.readFloat());
    frequency_ = in.readFloat();
    speed_ = in.readFloat();
    phase_ = in.readFloat();
    time_ = in.readFloat();
    return in.ok();
}
```

## 4. 通过代码编辑器新建插件

### 多文件编辑

编辑器支持同时打开多个源码文件：

- 上方标签栏切换文件；
- 标签可拖动排序；
- 未保存文件标题带 `*`；
- 关闭标签或编辑器时会提示保存；
- **新建插件先创建未保存标签，不会立刻写磁盘**；
- 只有点击 `↓ 保存`（或保存全部）后才真正生成文件；
- 只有检测到磁盘上已有同名源码，或已加载同名动态插件时，创建按钮才弹出覆盖确认。

### 第一步：打开工程

打开任意 `.math` 工程。

### 第二步：打开编辑器

按：

```text
Ctrl+`
```

### 第三步：新建源码

在 `新建插件源码` 区域填写：

```text
类名:    SineMotionPlugin
文件名:  sine_motion_plugin
```

点击：

```text
＋ 创建静态插件
```

编辑器会在：

```text
<工程根目录>/src/plugins/
```

生成：

```text
sine_motion_plugin.h
sine_motion_plugin.cpp
```

如果要走动态插件流程，点击：

```text
＋ 创建动态插件
```

它会生成：

```text
<源码根目录>/src/dynamic_plugins/editor_plugin.cpp
```

这是 C ABI 动态插件模板，不需要 `.h`。

### 第四步：编辑源码

把示例代码写入文件，点击：

```text
↓ 保存
```

### 双模式编辑器

窗口右上角按钮切换：

```text
动态模式
静态模式
```

动态模式：

- 保留对象列表；
- 只显示对象已挂载的动态插件；
- 只保留动态源码标签；
- 创建/编译/扫描/加载动态插件；
- 不显示静态插件相关内容。

静态模式：

- 不显示对象列表；
- 只显示已经编译进当前程序的静态插件；
- 只显示静态插件源码标签；
- 创建/保存/编译静态插件。

### 第六步：点击“编译并加载”

动态插件流程：

```text
＋ 创建动态插件
    ↓
编辑 editor_plugin.cpp
    ↓
点击“编译并加载”
```

静态插件流程：

```text
＋ 创建静态插件
    ↓
编辑 .h/.cpp
    ↓
保存
    ↓
点击“编译静态插件”
    ↓
自动关闭当前 MathStudio
    ↓
自动替换原 MathStudio.exe
    ↓
自动重新启动
```

`编译静态插件`使用独立目录 `build_static` 完成构建，
然后由替换脚本在当前进程退出后覆盖原可执行文件，并重新启动。

静态插件编译后会自动显示在静态模式的插件列表中，并通过
`plugin_registry` 自动注册，不需要手动修改 `plugin_factory.cpp`。

按钮会依次执行：

```text
保存源码
→ cmake --build --target MathStudioEditorPlugin
→ 复制 DLL 到 plugins/
→ 扫描动态插件
→ 创建插件
→ 挂载到当前 Object
```

不需要手动关闭程序。

如果编译失败，编辑器会显示编译日志的末尾内容。

### 源码目录配置

编辑器需要 CMake 源码根目录，优先级：

```text
MATHSTUDIO_SOURCE_DIR
    ↓
当前目录向上的 CMakeLists.txt
    ↓
D:/Program/VulkanProject/math
```

构建目录默认：

```text
<源码根目录>/build
```

可以覆盖：

```text
MATHSTUDIO_BUILD_DIR
```

CMake 路径默认：

```text
C:/Program Files/CMake/bin/cmake.exe
```

可以覆盖：

```text
MATHSTUDIO_CMAKE
```

### 第六步：注册插件工厂

打开：

```text
src/plugins/plugin_factory.cpp
```

加入头文件：

```cpp
#include "sine_motion_plugin.h"
```

加入类型分支：

```cpp
if (type == "SineMotionPlugin") {
    return std::make_unique<SineMotionPlugin>();
}
```

### 第七步：挂载到 Object

方式一：使用内置演示菜单。

```text
Object → 正弦运动立方体
```

方式二：在代码中挂载。

```cpp
Mesh cube = Mesh::loadFromResource("cube.mesh");

Object& object = window.addObject<Object>(
    std::move(cube),
    glm::vec3(0.0f),
    glm::vec4(0.76f, 0.84f, 1.0f, 1.0f),
    "正弦运动立方体");

object.addPlugin<SineMotionPlugin>(
    0.8f,   // 水平振幅
    0.35f,  // 垂直振幅
    3.0f,   // 曲线频率
    1.4f,   // 运动速度
    0.0f);  // 初始相位
```

## 7. 常见问题

### 插件列表中没有新插件

原因：

- 只创建了源码，没有重新编译；
- 没有在 `plugin_factory.cpp` 注册；
- 工程没有挂载该插件。

### 编辑器找不到源码

确认当前工作目录中有：

```text
src/plugins
```

发布包的源码目录只用于编辑器查看；编译应使用源码工程：

```text
D:\Program\VulkanProject\math
```

### 点击“应用到当前 Object”后没有运动

这是正常的：

```text
CodePlugin 只是源码标记
```

真实逻辑需要在重新编译后：

- 注册到插件工厂；
- 通过 `object.addPlugin<SineMotionPlugin>()` 挂载。

### 前视图方向不对

前视图：

```text
小键盘 1
```

退出正交：

```text
Esc
```
